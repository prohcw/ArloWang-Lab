ArloWang Lab — V5 导航栏微调（基于已修复闪屏的 V4）

本次仅更改 css/style.css，七个 HTML 和 js/main.js 均保持 V4 原样。

修改：
• 桌面导航栏高度约 76px → 60px；移动端约 67px → 56px。
• 顶部链接之间使用渐变分隔线，联系咨询按钮之前同样有分隔线。
• 当前页面导航呈轻微磨砂玻璃状态；点击时提供短暂按压反馈。
• 移动端折叠菜单保留，分隔线改为横向，展开按钮也有玻璃质感。

预览：解压全包，双击 index.html。本版本不需要本地服务器。
只替换 CSS：将本包 css/style.css 覆盖你 V4 网站的同名文件，刷新浏览器（Ctrl+F5）。

提示：file:// 多页站点点击时旧页面会被新文档替换，纯 CSS 无法维持“按下瞬间”的效果；新页面对应的导航条目会持续显示玻璃态（aria-current）。
