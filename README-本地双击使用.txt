ArloWang Lab 本地双击专用版 V4

1. 在一个全新目录解压整个 ZIP，双击 index.html。请勿将 v3 的 JS/CSS 与本版混用。
2. 本版的导航栏和页脚直接存在于每一个 HTML 中，无需等待 JS 生成。所有背景均保持正常显示。
3. 滚动进入视口的页面内容执行一次轻微浮现；页面打开时已经可见的内容直接呈现，不会先出现后消失。
4. 地址栏以 file:// 开头时，页面之间属于浏览器加载新文档；即使代码优化，也无法保证所有机器和浏览器完全零帧白屏。此版消除网站主动造成的整页淡出、动态插入导航和局部二次隐藏。
5. 如仍看到极短的浏览器级空白，正式发布时建议同域名 HTTPS 或本地静态 HTTP 环境，测试跨文档 View Transitions；但本包无需任何后端，也可以直接双击使用。
6. 控制台输入 window.ARLOWANG_SITE_BUILD 应得到 2026-09-25-file-local-v4。
7. 微信 xxx、联系表单与案例页仍为占位/演示内容。
